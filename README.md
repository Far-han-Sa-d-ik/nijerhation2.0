# Image Website

A minimal, responsive website that displays one image.

## Run locally
Open `index.html` in your browser.

## Publish with GitHub Pages
1. Create a GitHub repository and upload `index.html` and `nahian.jpg` to the repository root.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)`, then save.
5. Wait for GitHub Pages to publish the site; the URL will appear in the Pages settings.
